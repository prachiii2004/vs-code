VisionCanvas – AI Image Gallery App

VisionCanvas is a modern web application that allows users to upload, edit, organize, and share images in a clean and interactive gallery interface. The platform provides image management features along with basic editing tools to enhance and manage media efficiently.

The project focuses on creating a simple and user-friendly creative workspace for managing digital images with a responsive and modern design.



**URL**: https://snazzy-narwhal-7e6f7b.netlify.app/


## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
